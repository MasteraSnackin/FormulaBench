03 / current v2 controlled path

V2 constrains both the plan and the write

Each task gets one model call and at most one bounded repair or truncation-recovery call. A rejected plan leaves the submitted workbook pristine.

  1. 01Inspect

    Build bounded, formula-aware context from the task and initial workbook.

  2. 02Plan

    Ask Qwen3.8-27B for a typed, machine-checkable plan.

  3. 03Route

    Use fixed workbook operations, or screened Python for larger sheet changes.

  4. 04Validate

    Apply route-specific limits, formula checks and workbook controls.

  5. 05Publish

    Save and reopen an accepted output, or preserve the pristine input.

  6. 06Evaluate

    Recalculate in LibreOffice, then compare every required target cell.

05 / evaluation integrity

What this result shows, and what it does not

Supported by the evidence

  • The v2 wrapper replayed 400 retained outcomes with zero content mismatches.
  • The historical ExactSource source run passed 302 of 400 tasks.
  • The retained FormulaBench v1 run passed 133 of 400 tasks.
  • Two selected v2 route canaries passed their target-cell checks.

Not claimed

  • Migration parity is not a FormulaBench v2 benchmark score.
  • The historical ExactSource result is not transferred to FormulaBench v2.
  • Selected canaries cannot estimate the 400-task pass rate.
  • The screened Python route is not a general-purpose security sandbox.

06 / current v2 architecture

Fixed operations where possible, screened transformation code where necessary.
