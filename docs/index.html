03 / controlled path

FormulaBench treats the workbook as evidence

Each task gets one logical model sample. The model cannot run arbitrary Python, and FormulaBench never publishes a partial edit as a successful output.

  1. 01Inspect

    Read formula and cached-value views of the initial workbook.

  2. 02Context

    Build bounded, sheet-aware evidence with answer ranges first.

  3. 03Sample

    Ask Qwen3.8-27B once at temperature zero with thinking disabled.

  4. 04Validate

    Reject missing, duplicate, overlapping, outside or unsafe assignments.

  5. 05Write

    Apply to a fresh copy, save atomically and reopen for verification.

  6. 06Evaluate

    Recalculate in isolation, then use the organiser-supplied evaluator.

04 / the useful failure

Most wrong cells survived the structural checks.

05 / evaluation integrity

What this result shows, and what it does not

Supported by the evidence

  • All 400 public tasks produced outputs and were evaluated.
  • The fixed configuration passed 133 tasks.
  • Validation and replay are traceable task by task.
  • The code, predictions, outputs and evaluator result are public.

Not claimed

  • The public benchmark is not a statistically unseen holdout.
  • The 33.25% score is not an improvement over the organiser’s approximate 59% reference.
  • The two runs used materially different reasoning and output contracts.
  • Passing the static formula gate does not make active workbook content universally safe.
