Transcript

What the video says

  1. A workbook can open cleanly and still return the wrong investment answer.
  2. FormulaBench v2 reads bounded workbook context, then asks Qwen3.8-27B for a typed plan.
  3. Target cells use fixed workbook operations. Larger sheet changes may use screened Python with limited imports and resources.
  4. Rejected plans never touch the submission. V2 preserves the pristine workbook and records the fallback.
  5. Each task gets one model call, plus at most one bounded repair, before save and reopen checks.
  6. The organiser evaluator recalculates in LibreOffice and compares every target cell. Executable can still mean wrong.
  7. A credential-free migration replay checked 400 outcomes: 369 accepted plans, 31 pristine fallbacks and zero wrapper mismatches.
  8. That receipt establishes migration parity, not benchmark accuracy. FormulaBench v1 passed 133/400, the historical ExactSource source run passed 302/400, and no FormulaBench v2 score is claimed in this film.
